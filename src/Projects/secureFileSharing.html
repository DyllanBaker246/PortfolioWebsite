Secure File Sharing

Overview

Secure File Sharing is a web app that allows registered users to upload, store, preview, and share files using their browser. The system includes account registration with a unique email, login via server-side sessions, and role-based access for three user types: guest, registered user, and administrator. It also features personal file management, the ability to share files with other registered users, revoke access to shared files, a notification dashboard, and an admin portal for user management and system statistics. File contents are secured with AES symmetric encryption, while public key cryptography is used for access control and key exchange between file owners and recipients.

My contributions to the project included: Frontend, Backend, and Cloud implementation.
